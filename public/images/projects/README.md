## Video Support:
You can also drop `.mp4` or `.webm` files directly (e.g. `hero.mp4`) and set the file path in `/src/data/portfolioData.ts`.
Instagram Reel links can also be added directly to the `reels` array for each project in `/src/data/portfolioData.ts`.
